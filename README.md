## Rodando

O projeto utiliza um [Gradle Wrapper](https://docs.gradle.org/current/userguide/gradle_wrapper.html) embutido para o build, bastando apenas ter o [OpenJDK](https://openjdk.org/) 25+ instalado em sua máquina.

### Linux, Mac e BSD

```sh
./gradlew run
```

### Windows

```bat
.\gradlew.bat run
```
